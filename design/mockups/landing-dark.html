Product

The payment tools you need,
none of the custody you don’t.

Non-custodial by design

Customer payments go to wallets you control, not to an AirExpay balance. We never hold your funds.

Invoices and payment links

Create an invoice or a shareable link, send it to a customer and follow its status from one dashboard.

Developer-friendly

A documented REST API and signed webhooks, with a sandbox for testing integrations before going live.

How it works

From invoice to confirmation

Create an invoice or link

Set the amount, accepted assets and networks. Share the hosted checkout link or embed it.

Your customer pays

Checkout shows the exact amount, a QR code and a time-limited quote. Funds go to your wallet.

Track and reconcile

Follow each payment through confirming to paid, and receive a signed webhook at every step.

Developers

Built to integrate cleanly

A REST API with idempotent requests, signed webhooks you can verify, and a sandbox that simulates every payment state.

  • Every payment state, including underpaid and expired, testable in sandbox
  • HMAC-signed webhooks with automatic retries
  • Scoped API keys and team roles
Example
# Example request (sandbox)
curl https://api.airexpay.com/v1/invoices \
  -H "Authorization: Bearer sk_test_…" \
  -H "Idempotency-Key: order_8812" \
  -d amount="420.00" -d currency="USD" \
  -d accept="USDC:base,USDT:tron"
