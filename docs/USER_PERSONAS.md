# User Personas

1. **Sara — SaaS founder (Owner).** 5-person B2B SaaS, international customers who prefer USDT/USDC. Needs: invoices + API, clear fees, reliable webhooks. Fear: false "paid" states.
2. **Dev — Integrating engineer (Developer).** Wants OpenAPI, sandbox/mock mode, signed webhooks, idempotency, examples in JS/Python/PHP.
3. **Lina — Agency finance (Finance).** Needs payment history, CSV export, reconciliation with provider IDs, underpayment visibility.
4. **Omar — International freelancer (Owner, solo).** Wants payment links without code, mobile-friendly checkout, email receipts.
5. **Payer — End customer (no account).** Wants clear amount, network, QR, countdown, honest status; no signup.
6. **Support agent (Support / internal).** Read-only payment views, Intercom context without secrets.
